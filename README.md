# MiniGames — Story 1

This branch contains the implementation of **Story 1** of the MiniGames project for the RS School Qualifying Stage.  
Story 1 focuses on setting up the project infrastructure, configuring development tools, establishing the base architecture, and implementing the adaptive layout of the Home page and Auth dialog.

## Project Overview

MiniGames is a multi-stage SPA frontend project built without frameworks, using **TypeScript**, **Vite**, **SCSS**, and a custom component-based architecture.
