# MiniGames — Story-Based Frontend Project

This repository contains the implementation of the **MiniGames** project for the RS School qualifying stage.  
The project is structured into several **Stories (stages)**, each representing a separate development phase with its own tasks, requirements, and cross-check submission.

## Story Structure

- **Story 1** — Project setup, tooling configuration, base architecture, design tokens, UI Kit, and full adaptive layout of the Home page + Auth dialog.
  ...

Each Story is developed in its own branch (`story-1`, `story-2`, etc.) and submitted as an **unmerged Pull Request** according to RS School workflow rules.
